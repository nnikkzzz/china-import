# Синопуть — товары из Китая под ключ (лендинг)

## Что это
Лендинг сервиса импорта из Китая с белой растаможкой. Главная фишка — калькулятор итоговой стоимости в Hero (курс ЦБ, пошлина, НДС, логистика, сертификация, комиссия). Расчёт прикрепляется к заявке. Сейчас демо: бренд, контакты и тарифы вымышлены, клиентов нет.

## Стек
Next.js 15 (App Router, Turbopack) · TypeScript · Tailwind v4 · React Hook Form + Zod v4 · lucide-react. Деплой — Vercel.

## Структура
- `lib/config.ts` — ВСЕ тарифы: категории (пошлина/НДС/сертификат), способы доставки ($/кг, сроки, объёмный вес), комиссии, таможенный сбор, бренд
- `lib/calc.ts` — чистый движок расчёта (используется и калькулятором, и блоком «Примеры»)
- `lib/rates.ts` — курс ЦБ (cbr-xml-daily.ru, кэш 6 ч, fallback)
- `lib/lead-schema.ts` — Zod-схема заявки (общая для клиента и сервера)
- `app/api/lead/route.ts` — заявка → Telegram, rate limit 5/10 мин на IP, honeypot; без env — демо-режим
- `components/Calculator.tsx`, `LeadForm.tsx`, `calc-context.tsx` — client; секции в `components/sections/` — server

## Правила
- Тарифы менять только в `lib/config.ts`
- Тексты без фейковых отзывов и цифр «N клиентов», пока нет реальных
- Минимум client components

## Текущий фокус
Портфолио и проверка идеи (решено 2026-10-12). Работает концепт-режим `NEXT_PUBLIC_DEMO_MODE` (по умолчанию true): плашка «Концепт», noindex и robots Disallow, форма ничего не отправляет. Итог калькулятора показывается диапазоном ±12% (`ESTIMATE_SPREAD`). Есть /privacy (шаблон под 152-ФЗ с условным оператором).
Прод: https://china-import-ten.vercel.app (Vercel, аккаунт parshinnik8-2770, проект china-import). Из РФ открывается без VPN.
Деплой: `HTTPS_PROXY=http://127.0.0.1:10809 ./node_modules/.bin/vercel deploy --prod --yes` (CLI в devDependencies, API Vercel только через VPN-прокси). Env на Vercel: NEXT_PUBLIC_SITE_URL.
Дальше: OG-картинка, кейс для портфолио, свой домен.

## Уроки этого проекта
- Оценку на примерных тарифах показывать диапазоном, а не до копейки: точность до копеек выглядит как обещание
- Боевой режим без TELEGRAM_* отвечает 503, а не «успех», иначе заявки теряются молча
- Калькулятор и примеры на одном движке → примеры всегда сходятся с калькулятором и обновляются с курсом
