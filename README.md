# Синопуть: лендинг-калькулятор импорта из Китая

Концепт-лендинг сервиса «товары из Китая под ключ». Главная часть страницы — калькулятор итоговой стоимости прямо на первом экране. Он складывает в одну сумму товар по курсу ЦБ, оплату фабрике, логистику, страховку, пошлину, НДС, таможенный сбор, брокера, сертификацию и комиссию.

**Демо:** https://china-import-ten.vercel.app · **Кейс:** https://china-import-ten.vercel.app/case

> Компания, контакты и тарифы вымышлены. Расчёт ориентировочный (±12%), форма в демо-режиме ничего не отправляет.

## Возможности

- Калькулятор: 9 категорий товаров, ¥ или $, вес и объём партии, сравнение авто, ж/д, авиа и моря сразу по цене и сроку
- Детализация расчёта по 11 строкам, сумма НДС к вычету
- Курс ЦБ РФ на сервере с кэшем на 6 часов (ISR) и запасными значениями
- Расчёт прикрепляется к заявке. Форма: React Hook Form + Zod, honeypot, rate limit, отправка в Telegram
- Концепт-режим одним флагом: плашка, `noindex`, форма без отправки
- OG-картинки через `next/og` с живым примером расчёта, JSON-LD FAQPage, sitemap, политика конфиденциальности

## Стек

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · React Hook Form · Zod v4 · lucide-react · Vercel

## Структура

```
lib/config.ts        все тарифы, ставки и бренд
lib/calc.ts          движок расчёта (чистая функция)
lib/rates.ts         курс ЦБ
lib/og.tsx           шрифты и общие элементы OG-картинок
app/api/lead/        приём заявок
components/          калькулятор, форма, секции лендинга
app/case/            страница кейса
```

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

| Переменная | Назначение |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | адрес сайта для canonical, sitemap и OG |
| `NEXT_PUBLIC_DEMO_MODE` | `true` по умолчанию; `false` — боевой режим |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | куда отправлять заявки в боевом режиме |
